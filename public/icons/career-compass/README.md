# Career Compass explorer icons

Twelve original, editable SVG assets inspired by the supplied compass reference.

- Canvas: 256 × 256; transparent background.
- Palette: deep navy #1B2A4A, compass gold #D4A017, parchment #F5ECD7 with aged brass shading.
- Stroke system: 2–2.6 px silhouettes, 1–1.8 px structural detail, 0.7–0.9 px engraving.
- Recommended display: 64–128 px; fine engraving is intended for 96 px and larger.
- No embedded raster images, fonts, scripts, external dependencies, or background rectangles.
- Gradient and filter IDs are uniquely prefixed for inline use.
- Wax seal center is empty and transparent. Fog is deliberately translucent.
- Footprint trail is a square connector; rotate or repeat rather than stretching.
- preview.svg is a presentation sheet, not a transparent production icon.

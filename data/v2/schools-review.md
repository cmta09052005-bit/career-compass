# School source and mapping review

Source filename: Updated_List_ng_mga_School_v1.pdf. Internal header: Bersyon 3 - na-update noong October 25, 2026. The internal version is retained as supplied. This is a transcription and qualification review, not independent verification of school offerings.

One record is retained per PDF table row (51 records). Rows containing several campuses or several institutions remain combined; no offerings were assigned to newly invented campus/institution rows. A combined row is not one verified physical school. Source abbreviations and malformed line-wrapped labels are preserved rather than expanded into guessed URLs.

sourceLevel describes the strongest identifiable supplied source, not independent confirmation: official includes named institutional/CHED/LGU/accreditor sources; secondary includes directories, Wikipedia, news and research; weak includes explicitly weak evidence and unresolved source identity; none means the source cell is blank. Mixed sources remain in sourceNames. Source specificity and official status of abbreviation-only citations remain NOT DETERMINED.

The major-only flag means the row contains one or more major/specialization-limited offerings; it does not mean every program in the row is restricted to a major. derived-location covers the PDF community-college location note and inferred provinces for unambiguous named localities.

 


CAREER COMPASS: A WEB-BASED DECISION SUPPORT SYSTEM FOR SENIOR HIGH SCHOOL CAREER GUIDANCE

Site Map / Information Architecture 
Version 1.0


Purpose of this document: A Site Map is a structural outline that lists every screen in Career Compass and how they connect to one another, without yet showing visual design or layout details. It functions as the system's blueprint, establishing the complete navigation flow (from Landing Page through the assessment sections to Results and PDF export) before any wireframing, diagramming, or coding begins. This document serves as the shared reference point that keeps all other Phase 4 outputs (wireframes, diagrams, features table) consistent with one another, and later becomes part of Chapter 4's System Development and Design documentation.

1.	LANDING / WELCOME PAGE
•	Explorer/Journey introduction ("You are an Explorer. Your career path is a map.")
•	Short description of the system's purpose
•	"Start Your Journey" button

2.	STUDENT INFO INTAKE (session-only — not an account)
•	Nickname / First Name (optional, for personalization only)
•	Strand (Academic-STEM, Academic-ABM, Academic-HUMSS, TVL, Arts & Design, Sports)
•	Current Year Level (Grade 11 / Grade 12) — display/personalization only, not scored
•	"Continue" button

3.	JOURNEY MAP / DASHBOARD (Main Navigation Hub)
•	Visual "island map" showing 3 assessment sections
•	Compass Points Progress Indicators
•	Sections unlock and must be completed in sequence (Interests → Skills → Academic Performance); only the next incomplete section is accessible at any time — no free jumping ahead.
•	Journey Guide icon (first-time help overlay explaining map navigation) 
•	"Locate Me" button (centers/highlights current or next section on the map)
•	"View My Results" button (enabled once all 3 sections are completed)
•	Session Options (Restart Assessment, Sound On/Off) — session-only, not saved between visits
•	"Start Assessment" button (shown only before any section has been started if not, “Start” changes to “Continue”

3a. INTERESTS SECTION
-	Scenario-based card selection (6–8 scenarios)
3b. SKILLS SECTION
-	Self-assessment confidence sliders (8–10 statements)
3c. ACADEMIC PERFORMANCE SECTION
-	Step-by-step form input (general average, best-performing subjects) – Note: Strand is already captured in Step 2 and is not re-entered here

4.	PROCESSING / ASSESSMENT SUMMARY (transition screen)
•	Brief loading/computing animation
•	Rule-based weighted scoring engine computes category + course scores (in-session only)

5.	RESULTS PAGE
•	Top-match category label (e.g., "Technology and Computing – Top Match")
•	Ranked list of recommended courses with match percentages
•	"Explore This Course" button per course card
•	"Back to Journey Map" button
•	"Download My Explorer Report" (PDF export) button

5a. COURSE DETAIL VIEW (opened per selected course)
-	Overview (description + key subjects)
-	Schools (name, location, public/private)
-	Career Opportunities (job titles, salary range)
-	Guidance Tips (admission requirements, scholarships, certifications — optionally adjusted based on Grade 11 vs. Grade 12 for relevance)
6.	PDF REPORT CONFIRMATION
•	"Your Explorer Report is ready" confirmation screen
•	Download/print action complete

 CAREER COMPASS: A WEB-BASED DECISION SUPPORT SYSTEM FOR SENIOR HIGH SCHOOL CAREER GUIDANCE

Career Dataset (Spreadsheet)
Version 1.0

Purpose of this document: The Career Dataset is the static reference library of all 24 courses Career Compass can recommend, organized under six CHED-based categories. For each course, it provides an overview, partner school options with locations, related career opportunities with salary estimates (with source and reference date), and guidance tips for students. This dataset is what actually populates the Results Page and Course Detail View once a student receives their recommendation — it's the "content" layer of the system, separate from the "logic" layer defined in the Scoring Table, and it's built entirely from static files rather than a live database, consistent with the system's no-database scope.
